# Two Box Roll-Off Trailers

BENLEE pull-behind roll-off trailers that carry two roll-off boxes at once, for waste hauling.

## Key specs
Figures come from Vac2Go's own website, as recorded in a Vac2Go spec reference.
- Manufacturer: BENLEE {src: Vac2Go Two Box Roll-Off Trailer spec reference (vac2go.com) p.1}
- Box sizes: 20, 30, 40 and 50 yard {src: Vac2Go Two Box Roll-Off Trailer spec reference (vac2go.com) p.1}
- Weight capacity: "80,000 lb" {src: Vac2Go Two Box Roll-Off Trailer spec reference (vac2go.com) p.1}
- Load capacity: "Two full loads, more than 20 tons" {src: Vac2Go Two Box Roll-Off Trailer spec reference (vac2go.com) p.1}

## Typical uses
- Waste hauling.

## Standard and optional
- The source does not separate standard from optional equipment.

## Not in our literature
- Model number, axles, dimensions, empty weight, hoist or roll-off mechanism, hitch, which box sizes can be paired on the trailer, and whether boxes are included in the rental. A Vac2Go rep can confirm these.

## Notes for the advisor
- Quote "80,000 lb" exactly as worded, as the listed weight capacity. The source does not define it: it is not clearly stated to be trailer payload, GVWR or gross combination weight. Do not describe it as payload.
- Quote "Two full loads, more than 20 tons" exactly. The source does not say whether the tonnage is per box or combined.
- Do not promise box sizes or box inclusion; a rep can confirm.
