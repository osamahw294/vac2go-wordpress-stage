# Roll-Off Trucks

Roll-off hoist trucks that load, haul and unload roll-off containers, commonly used for construction and demolition waste and other waste types.

## Key specs
Figures come from Vac2Go's own website, as recorded in a Vac2Go spec reference.
- Hoist: "80K outside roll-off hoist" {src: Vac2Go Roll-Off Truck spec reference (vac2go.com) p.1}
- Operation: automatic and manual available {src: Vac2Go Roll-Off Truck spec reference (vac2go.com) p.1}
- Side rollers: four per side {src: Vac2Go Roll-Off Truck spec reference (vac2go.com) p.1}
- Configuration: tandem / pusher {src: Vac2Go Roll-Off Truck spec reference (vac2go.com) p.1}
- Hoist alarm: included {src: Vac2Go Roll-Off Truck spec reference (vac2go.com) p.1}
- Tarper: auto tarper {src: Vac2Go Roll-Off Truck spec reference (vac2go.com) p.1}

## Typical uses
- Waste hauling, including construction and demolition waste in roll-off containers.

## Standard and optional
- Standard: hoist alarm, auto tarper.
- Choice: automatic or manual operation (see notes).

## Not in our literature
- Hoist make and model, chassis make and model, engine, GVWR, dimensions, and which container sizes the truck accepts. A Vac2Go rep can confirm these.

## Notes for the advisor
- Quote the hoist as "80K" as printed; the source gives no unit.
- "Automatic and manual available" does not say whether it refers to the transmission or the hoist controls. Do not commit to either for a given rental; a rep can confirm.
- The trucks are built from different chassis paired with a branded hoist, so details vary by unit.
