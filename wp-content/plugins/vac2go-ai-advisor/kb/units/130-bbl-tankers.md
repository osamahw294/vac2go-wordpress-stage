# 130 BBL Tankers

Pull-behind waste hauling tanker trailers in the 130 BBL capacity class, built by Dragon, Huber and ITI, and set up with a range of pump and axle options.

## Key specs
Figures are as Vac2Go publishes them.
- Tank capacity: 130 BBL {src: Vac2Go 130 BBL Tanker spec reference (vac2go.com) p.1}
- Volume: 5,460 gallons {src: Vac2Go 130 BBL Tanker spec reference (vac2go.com) p.1}
- Tank material: carbon steel {src: Vac2Go 130 BBL Tanker spec reference (vac2go.com) p.1}
- Stainless steel: option available {src: Vac2Go 130 BBL Tanker spec reference (vac2go.com) p.1}
- Certification: DOT / ASME {src: Vac2Go 130 BBL Tanker spec reference (vac2go.com) p.1}
- Pump options: multiple, configurable {src: Vac2Go 130 BBL Tanker spec reference (vac2go.com) p.1}
- Axle configurations: multiple, configurable {src: Vac2Go 130 BBL Tanker spec reference (vac2go.com) p.1}

## Typical uses
- Waste hauling.

## Standard and optional
- Standard: carbon steel tank.
- Optional: stainless steel tank. Pump and axle setups vary by unit.

## Not covered
- Pump type and model, CFM and vacuum rating, hose sizes, dimensions, weights/GVWR, axle count, hitch. A Vac2Go rep can confirm these.

## Notes for the advisor
- The fleet is built by more than one manufacturer (Dragon, Huber, ITI), so pump, axle setup and tank material depend on the unit. Do not promise a specific pump, axle setup or a stainless tank.
- "DOT / ASME" is listed, but it is not stated that every tanker in the fleet carries that certification. For hazmat or code-certified hauling, a rep must confirm the specific unit.
- No pump figures are published, so do not quote CFM or vacuum.
